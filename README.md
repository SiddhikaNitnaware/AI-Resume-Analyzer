## AI-Powered Resume Analyzer
An intelligent web app that analyzes resumes against job descriptions to calculate match score, identify missing skills, and check ATS compatibility. It helps candidates optimize their resumes for better chances of selection.

# Demo: https://siddhikanitnaware-ai-resume-analyzer-app-jammle.streamlit.app/

# Tech Stack:
-Frontend: Streamlit
-NLP: spaCy
-ML: scikit-learn
-PDF Processing: PyMuPDF

# Usage:
Upload resume --> Paste job description --> Click Analyze Resume --> View results.
